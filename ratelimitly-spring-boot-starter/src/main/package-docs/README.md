# RateLimitly Spring Boot starter

This artifact contains no Java source: it is a dependency-only starter.
Its POM brings in `ratelimitly-spring-boot-autoconfigure` and Spring Boot's starter.
The corresponding autoconfigure artifact provides the Java implementation,
source archive, and generated API documentation.

Application examples and configuration:
https://github.com/ratelimitly-com/rl-spring#readme
